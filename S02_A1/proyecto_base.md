# StockIV - Aplicación web para el control de inventario

StockIV es una aplicación web pensada para llevar el control del inventario de una tienda de ropa, calzado y artículos deportivos. La idea surge de la necesidad de tener en un solo lugar la información de los productos disponibles, sus precios y existencias, evitando depender de registros manuales o archivos separados que pueden quedar desactualizados.

La aplicación estará dirigida al propietario y al personal encargado del inventario. Desde el sistema podrán registrar nuevos productos, consultar los artículos disponibles, actualizar cantidades, modificar información y eliminar registros cuando sea necesario. Cada usuario deberá iniciar sesión para acceder a las funciones del sistema.

El objetivo de StockIV es facilitar la administración diaria del inventario mediante una herramienta sencilla y accesible desde un navegador. Para esta primera versión, el proyecto se concentrará únicamente en el manejo de productos y existencias, sin incluir procesos de venta, facturación o pagos.
